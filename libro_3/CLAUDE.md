# Bernal's English Course — Third Book (rebuild notes)

Same architecture as `libro_1`/`libro_2`: `index.html` is the data-driven renderer, `content/book.json` lists the parts, each `content/<f>.json` = {running, pages:[{src:[...], blocks:[...]}]}.

- Source: `uploads/bernals-english-course-third-book.pdf` (131 scanned pages) → `scan/pNNN.jpg` (827x1169). Printed page 37 is missing from the scan, so from there on scan page = printed page − 1. `src` values are approximate printed pages.
- 25 lessons (l01–l25). Front = cover (art `img/v/cover-art.svg`, green palette) + title page.
- Content is generated by `tools/l*.py` (helpers in `tools/h.py`): edit the script and run `python3 tools/lNN.py` from `tools/`, it rewrites `content/lNN.json` and `tools/jobs/lNN.json`.
- Illustrations: `python3 -I tools/art.py tools/jobs/<lesson>.json [--only a,b]` → `img/v/<name>.svg` (see libro_2/CLAUDE.md for job format).
